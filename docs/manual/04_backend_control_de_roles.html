📘 Capítulo 4: Control de Acceso por Rol (`requireRole`)

Middleware atómico para verificar permisos de rol (RBAC)

Código del Middleware `requireRole`

Este interceptor se encarga únicamente de comparar el rol del usuario contra el rol permitido:

// src/middleware/auth.middleware.ts
export const requireRole = (requiredRole: number) => {
  return (req: AuthRequest, res: Response, next: NextFunction) => {
    const userRoleNumber = Number(req.userRole);
    if (!userRoleNumber || userRoleNumber !== requiredRole) {
      return res.status(403).json({ error: 'Acceso denegado. Permisos insuficientes.' });
    }
    next();
  };
};
💡 Responsabilidad Única: Función de orden superior que recibe requiredRole. Si req.userRole no coincide, responde 403 Forbidden. No valida la firma del token (esa es responsabilidad del middleware anterior).
