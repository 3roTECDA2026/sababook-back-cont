📘 Capítulo 3: Verificación de Firma JWT

Interceptor 1 — Verificación de autenticidad del Token Bearer

1️⃣ Interceptor `verifyToken`

Comprueba que la petición traiga un token de sesión auténtico y no alterado en la cabecera HTTP.

// Interceptor 1: Verificar firma JWT (verifyToken)
export const verifyToken = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ message: 'No token' });

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.userRole = decoded.rol_id;
    next(); // Firma válida: avanza al siguiente middleware
  } catch {
    return res.status(401).json({ message: 'Invalid token' });
  }
};
💡 ¿Cómo funciona? Extrae el token del encabezado Authorization: Bearer <token>. Si falta o la firma no coincide con el JWT_SECRET, detiene la ejecución devolviendo 401 Unauthorized. Si es válido, inyecta el rol en req.userRole.
