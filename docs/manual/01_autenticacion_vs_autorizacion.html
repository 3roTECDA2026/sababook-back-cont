Capítulo 1: Autenticación vs Autorización

Manual de Aprendizaje — Instituto 166

🔑 Autenticación (¿Quién sos?)

Proceso de verificar la identidad del usuario en la entrada (ej. email y contraseña con bcrypt).

🛡️ Autorización (¿Qué podés hacer?)

Proceso de verificar si un usuario autenticado tiene permisos para realizar una acción o acceder a una ruta.
