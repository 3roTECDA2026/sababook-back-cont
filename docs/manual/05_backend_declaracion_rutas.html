📘 Capítulo 5: Encadenamiento en Express Router

Composición declarativa de middlewares en la definición de rutas

Declaración en Router

Unimos los middlewares estudiados previamente en la declaración del endpoint:

// src/routes/moderacion.routes.ts
import { Router } from 'express';
import { verifyToken, requireRole } from '@/middleware/auth.middleware';
import moderationController from '@/controllers/moderation.controller';

const router = Router();

// Encadenamiento de izquierda a derecha
router.post('/config', verifyToken, requireRole(1), moderationController.saveConfig);

export default router;
💡 Responsabilidad Única: La capa de enrutamiento solo se encarga de componer la secuencia: 1° verifyToken, 2° requireRole(1) y 3° moderationController.saveConfig.
