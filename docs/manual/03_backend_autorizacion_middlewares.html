Capítulo 3 — Diapositivas explicativas de implementación

SLIDE 1 / 3

1️⃣ Verificación de Firma JWT (`verifyToken`)

El primer interceptor comprueba que la petición traiga un token de sesión auténtico y no alterado en la cabecera HTTP.

// Interceptor 1: Verificar firma JWT (verifyToken)
export const verifyToken = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ message: 'No token' });

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.userRole = decoded.rol_id;
    next(); // Firma válida: avanza al siguiente middleware
  } catch {
    return res.status(401).json({ message: 'Invalid token' });
  }
};
💡 ¿Cómo funciona? Extrae el token del encabezado Authorization: Bearer <token>. Si falta o la firma no coincide con el JWT_SECRET, frena todo devolviendo 401 Unauthorized. Si es válido, inyecta el rol en req.userRole.
SLIDE 2 / 3

2️⃣ Control de Acceso por Rol (`requireRole`)

El segundo interceptor evalúa si el rol del usuario autenticado coincide con el nivel de acceso requerido.

// Interceptor 2: Verificar Rol (requireRole)
export const requireRole = (roleId) => (req, res, next) => {
  if (req.userRole !== roleId) {
    return res.status(403).json({ error: 'Acceso denegado' });
  }
  next(); // Rol correcto: pasa al controlador final
};
💡 ¿Cómo funciona? Es una función de orden superior que recibe el ID de rol permitido (ej. 1 para Administrador). Compara req.userRole. Si no tiene permiso, bloquea la petición enviando 403 Forbidden antes de llegar a la base de datos.
SLIDE 3 / 3

3️⃣ Declaración en la Capa de Ruteo (Router)

Finalmente, unimos las piezas encadenando los interceptores directamente en la definición de la ruta.

// Declaración en la capa de ruteo Express
router.post('/admin/config', verifyToken, requireRole(1), adminController.save);
💡 ¿Cómo funciona? Express ejecuta de izquierda a derecha. Primero valida la firma (verifyToken), luego valida el rol (requireRole(1)), y solo si ambos dan el OK (next()), ejecuta la función del controlador (adminController.save).
