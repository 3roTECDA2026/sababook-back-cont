🍪 Guía: Autenticación por Sesiones Tradicionales

Método con Cookies Stateful y `express-session`

1. ¿Cómo Funciona el Método Tradicional por Sesión?

A diferencia de JWT donde el cliente guarda el token, en el modelo tradicional con Sesiones:

  • El servidor crea una sesión en RAM o Redis al hacer Login.
  • Envía una cookie segura connect.sid cifrada al navegador.
  • En cada petición, la cookie se envía automáticamente y el servidor busca la sesión en memoria/DB.

2. Configuración de `express-session`

📦 Importaciones requeridas:
import express from 'express';
import session from 'express-session';

Configuración del middleware de sesión en el archivo principal del servidor (server.ts):

app.use(session({
  secret: process.env.SESSION_SECRET!,
  resave: false,
  saveUninitialized: false,
  cookie: {
    secure: process.env.NODE_ENV === 'production',
    httpOnly: true, // Previene lectura desde JavaScript en frontend (CSRF/XSS)
    maxAge: 1000 * 60 * 60 * 24 // 24 horas
  }
}));

3. Middleware de Verificación de Sesión (`requireSession`)

📦 Importaciones requeridas:
import { Request, Response, NextFunction } from 'express';

Middleware backend para verificar si el usuario tiene una sesión activa:

export const requireSession = (req: Request, res: Response, next: NextFunction) => {
  if (!req.session || !(req.session as any).user) {
    return res.status(401).json({ message: 'No hay sesión activa' });
  }
  next();
};

4. `requireSession` — Casos de Éxito vs Falla

✅ Caso de Éxito: Cookie Válida con Sesión Activa

El navegador adjunta la cookie connect.sid. El servidor la desencripta, encuentra la sesión en RAM/DB con user.rol === 1.

➜ Se habilita la petición y se ejecuta next().

❌ Caso de Falla 1: Cookie Inexistente o Expirada

El navegador no envía la cookie o la sesión expiró en el servidor.

➜ Retorna HTTP 401 Unauthorized con { message: "No hay sesión activa" }.

❌ Caso de Falla 2: Destrucción de Sesión (Logout)

El usuario hace logout ejecutando req.session.destroy().

➜ Las peticiones posteriores fallan con 401 Unauthorized.
