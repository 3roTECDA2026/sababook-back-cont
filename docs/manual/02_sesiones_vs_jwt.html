Capítulo 2: Modelos de Autenticación (Sesiones vs JWT)

Manual de Aprendizaje — Instituto 166

🍪 Sesiones Tradicionales (Stateful)

El servidor guarda el ID de sesión en memoria/DB y envía una cookie al navegador. Exige sincronización entre servidores al escalar.

🪙 JSON Web Tokens (Stateless)

El servidor envía un pasaporte firmado. El cliente lo adjunta en Authorization: Bearer <token>. Cualquier servidor valida la firma sin consultar la base de datos.
