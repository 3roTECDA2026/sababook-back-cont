1. ¿Por qué usamos JSON Web Tokens (JWT)?

Un JWT es un estándar firmado digitalmente que permite enviar datos de autenticación seguros entre el cliente (React) y el servidor (Express) sin necesidad de mantener sesiones guardadas en el servidor.

Comparativa de Alternativas

Característica Sesiones Tradicionales (Cookies) JWT (Bearer Tokens)
Almacenamiento en Servidor Requiere guardar la sesión en memoria/base de datos. Stateless: El servidor no guarda estado.
Escalabilidad Dificultad al escalar múltiples servidores. Alta: Cualquier backend valida la firma.
Compatibilidad Móvil / API Sujeto a restricciones CORS y manejo de cookies. Universal: Envíos vía Header HTTP.

2. Implementación Backend: Middlewares

El backend utiliza dos middlewares clave en la cadena de ejecución de Express:

A. Verificación del Token (verifyToken)

Extrae el token del encabezado Authorization: Bearer <token> y valida su integridad.

export const verifyToken = (req: AuthRequest, res: Response, next: NextFunction) => {
  const authHeader = req.headers.authorization;
  if (!authHeader || !authHeader.startsWith('Bearer ')) {
    return res.status(401).json({ message: 'No token provided' });
  }

  const token = authHeader.split(' ')[1];
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET as string);
    req.userId = decoded.usuario_id;
    req.userRole = decoded.rol_id;
    next();
  } catch (error) {
    return res.status(401).json({ message: 'Invalid token' });
  }
};

B. Control de Acceso por Rol (requireRole)

export const requireRole = (requiredRole: number) => {
  return (req: AuthRequest, res: Response, next: NextFunction) => {
    if (Number(req.userRole) !== requiredRole) {
      return res.status(403).json({ error: 'Acceso denegado.' });
    }
    next();
  };
};

3. Protección de Rutas en el Frontend (React)

En el cliente, las rutas privadas se envuelven en el componente ProtectedRoute para evitar accesos no autorizados en la navegación.

export const ProtectedRoute = ({ children }: { children: ReactNode }) => {
  const { isAuthenticated, loading } = useAuth();

  if (loading) return <div>Cargando...</div>;
  if (!isAuthenticated) return <Navigate to="/login" replace />;

  return <>{children}</>;
};
